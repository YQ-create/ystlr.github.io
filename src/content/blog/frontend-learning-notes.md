最近重新梳理了一遍前端基础知识。每次觉得自己「都会了」，回头看基础文档总能发现之前漏掉的细节。
这篇笔记记录几个感触最深的点，后续会持续补充。

## 一、先理解浏览器在做什么

写页面之前，先想清楚两件事：

1. 浏览器收到 HTML 后如何构建 DOM 树；
2. CSS 如何被解析、布局、绘制。

理解了这一条主线，再去看框架和工程化工具，就不会觉得它们是黑盒。

## 二、CSS 布局从盒模型开始

很多样式问题的根源，都可以回到盒模型和文档流上找答案。一个常见的属性组合：

```css
.card {
	display: flex;
	flex-direction: column;
	gap: 1rem;
	max-width: 720px;
	margin: 0 auto;
}
```

Flex、Grid、定位各自适合什么场景，用多了自然会有判断。
关键是遇到布局错位时，知道先用开发者工具检查盒子到底占了多少空间。

## 三、读官方文档，而不是只看教程

教程适合入门，但它会省略边界情况。官方文档里的示例、参数说明和兼容性表格，
才是解决真实问题的依据。养成遇到问题先查文档的习惯，比收藏一百篇教程更有用。
