这是本站的第一篇文章。长期以来一直想有一个属于自己的写作空间，不依附于任何社交平台，
页面干净、内容由自己完全掌控。现在，它终于上线了。

## 为什么是 Astro

在对比过几个静态博客方案之后，我最终选择了 **Astro**：

- 构建产物是纯静态 HTML，加载快、托管便宜；
- 写作方式就是普通的 Markdown 文件，一篇文章对应一个文件；
- 组件化的页面结构，以后想加功能也方便扩展；
- 配合 GitHub Actions，可以在推送代码后自动部署到 GitHub Pages。

## 站点目录

写作时只需要关心 `src/content/blog/` 目录：每一个 `.md` 文件就是一篇文章，
文件的 `frontmatter` 里填写标题、摘要、发布日期和标签。

```bash
# 本地启动预览
npm run dev

# 构建静态产物
npm run build
```
