# 知识库

这是一个独立的**知识笔记**空间，与「文章」里的日常随笔分开，专门沉淀成体系的东西。

## 怎么加笔记

在 `src/content/knowledge/` 目录下新建一个 `.md` 文件，frontmatter 里填：

```yaml
---
title: "笔记标题"
description: "一句话简介"
pubDate: 2026-10-29
category: "分类名"
tags: ["标签1", "标签2"]
pinned: false
---
```

正文用 Markdown 写即可，提交后会自动出现在「知识库」页，按分类分组展示。

## 分类建议

- **前端**：框架、构建、工程化的经验总结
- **工具**：效率工具、命令行、工作流
- **阅读**：读书笔记、方法论提炼
- **生活**：可持续的小习惯、心法
