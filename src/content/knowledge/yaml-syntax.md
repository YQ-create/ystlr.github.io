YAML 的设计目标是「给人读的配置」，代价是**缩进和类型推断都很敏感**。多数诡异问题不是解析器有 bug，而是某个键被解析成了布尔值，或者 Tab 混进了空格缩进。

## 基本结构

```yaml
# 映射：键值用冒号 + 空格
name: my-site
version: 1.0
enabled: true

# 列表
tags:
  - 前端
  - 配置

# 列表里套映射
services:
  - name: web
    port: 8080
  - name: db
    port: 5432

# 行内写法（短结构才用）
labels: { env: prod, tier: web }
```

| 规则 | 说明 |
| --- | --- |
| 缩进 | **只用空格**，同级元素缩进一致；缩进层级表示嵌套 |
| `: ` | 冒号后必须有空格才是键值分隔（URL 里的 `:` 不受影响） |
| `- ` | 短横后必须有空格才是列表项 |
| `#` | 行内注释，前面要有空格；在引号内只是普通字符 |
| 文档分隔 | `---` 开始、`...` 结束，单文件多文档时用 |
| 文件扩展 | `.yaml` / `.yml` 都可，同一项目里统一一种 |

**禁止 Tab** 是最常见也最难查的错误：编辑器里看不出差别，解析器直接报错。

## 类型与容易误判的值

```yaml
# 这些是不同类型，别凭直觉写
port: 8080            # 整数
ratio: 0.5            # 浮点
debug: true           # 布尔
nothing: null         # 空（也可写 ~）
when: 2026-11-09      # 日期（YAML 1.1 解析器会转成日期对象）
version: "1.10"       # 字符串（不加引号会被当浮点 1.1）
name: "yes"           # 字符串（不加引号在部分解析器里是布尔 true）
```

| 想表达 | 写法 |
| --- | --- |
| 字符串形式的数字/版本号 | 加引号 `"1.10"` |
| 布尔值 | `true` / `false`（YAML 1.2）；避免 `yes` / `on` / `off` |
| 空值 | `null` 或 `~` |
| 字面量冒号、井号、`{` | 加引号 |
| 强制字符串 | 引号，必要时 `!!str` 标签 |

GitHub Actions 里 `on:` 被 YAML 1.1 解析成布尔 `true` 是经典坑 —— 配置本身没错，是不同解析器对键名的类型推断不同。

## 多行字符串

```yaml
# 折叠 > ：换行变空格，适合长描述
description: >
  这是一段很长的说明，
  换行会被折成空格，
  末尾保留一个换行。

# 保留 | ：换行原样保留，适合脚本、证书、Nginx 片段
script: |
  #!/usr/bin/env bash
  set -euo pipefail
  npm ci
  npm run build
```

| 记号 | 含义 |
| --- | --- |
| `\|` | 保留换行（literal） |
| `>` | 折叠换行为空格（folded） |
| `\|-` / `>-` | 去掉末尾换行 |
| `\|+` / `>+` | 保留全部末尾空行 |

缩进由**第一行非空内容的缩进**决定，后面少缩进一格就提前结束块，脚本里最容易在这里悄悄截断。

## 锚点与合并

```yaml
defaults: &defaults
  retries: 3
  timeout: 30s

web:
  <<: *defaults      # 合并映射
  timeout: 60s       # 覆盖其中一个键

db:
  <<: *defaults
```

`&name` 定义锚点、`*name` 引用、`<<:` 合并映射。能减少重复，但**别过度使用**：配置被拆到多处后，追踪一个值的来源反而更难。

## 容易踩的坑

- **混用 Tab 和空格**：直接解析失败，编辑器开启「显示空白字符」能省很多时间。
- **冒号后漏空格**：`key:value` 会被当成一个字符串而不是键值。
- **版本号不加引号**：`1.10` 变 `1.1`，`2.0` 变 `2.0` 浮点，比较和展示都出错。
- **`on` / `yes` / `no` 当普通字符串**：部分解析器转成布尔，键名和值都可能中招，一律加引号更保险。
- **多行块缩进不一致**：脚本后半段被截断，CI 里表现为「命令莫名少了几行」。
- **用 `<<:` 合并却忘了覆盖顺序**：后面的同名键才生效，顺序写反会得到旧值。
- **在 YAML 里写表达式或模板而不引号**：`${{ }}`、`{{ }}`、以 `*` / `&` / `!` 开头的值都需要引号。
- **把缩进当成「好看」随意调整**：YAML 的缩进是语法，不是排版。
